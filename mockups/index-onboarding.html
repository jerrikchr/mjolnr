Model-to-Role Routing & Multi-Model Council

smed doesn't rely on a single model's blind spots. You can assign specific provider models to specialized roles under .smed/routes/*.yaml and configure one bounded advisory council under .smed/council.yaml.

Why Use an Advisory Council? For a PRD or plan, several configured routes can surface independent positions and preserved dissent. Findings inform a human disposition; they never vote to approve a tool or authorize a side effect.

Set Default Policy Gate Tier

smed's core promise is governed execution: code proposes, smed disposes. Pick your default operating policy gate tier.

read-only
smed can inspect state and read files, but cannot execute commands or mutate code.
ask (Recommended) ★ Default
smed prompts for human approval before executing any file mutation or shell command.
write (Pre-Approved)
In-workspace file changes are pre-approved. Out-of-workspace actions still trigger a policy gate.
